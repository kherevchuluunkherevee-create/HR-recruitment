# TalentFlow — Сонгон шалгаруулалтын удирдлага

## Ажиллуулах
1. Node.js 20+ суулгана.
2. `npm install`
3. `npm run dev`
4. Үйлдвэрлэлийн build: `npm run build`

## Боломжууд
- Монгол/Англи интерфейс, light/dark горим, role switcher
- KPI болон аналитик графикууд, шүүлтүүрүүд
- Ажлын байрны захиалга, urgency, автоматаар тооцох deadline, тайлбартай өөрчлөлтийн түүх
- 60+ нэр дэвшигч, Kanban pipeline, drag-and-drop шат солих
- Ярилцлага, бүтэцлэгдсэн үнэлгээ, туршилтын хугацааны 3 үнэлгээ
- localStorage persistence, CSV болон PDF экспорт
- Gemini туслахын аюулгүй client contract жишээ

## Өгөгдөл ба нууцлал
Жишээ өгөгдөл нь demo зорилготой. CV, үнэлгээ, холбоо барих мэдээлэл нь хувийн мэдээлэл тул бодит хэрэглээнд role-based backend authorization, аудитын бүртгэл, хадгалалтын бодлого, шифрлэлт шаардлагатай. AI нь зөвхөн зөвлөмж өгнө; хүний шийдвэрийг орлохгүй.
Gemini түлхүүрийг browser-д ил гаргах `VITE_GEMINI_API_KEY` хэлбэрээр бүү байрлуул. `GEMINI_API_KEY`-г сервер талын proxy/API route-д хадгална.
